## 需重点学习

以下要点来自参考答案本身，供查漏补缺：

1. **74 题 注解的基本定义**
   - 注解是 Java 5 引入的新特性（`Annotation`）
   - 可看作一种特殊的注释，用于修饰类、方法或者变量
   - 本质是一个继承了 `Annotation` 的特殊接口
   - 提供某些信息供程序在编译或者运行时使用
   - JDK 内置注解（`@Override`、`@Deprecated`），同时可自定义注解

2. **75 题 注解的解析方法（两种）**
   - 编译期直接扫描：编译器在编译时扫描并处理注解，如 `@Override` 检测方法是否重写父类方法；
   - 运行期通过反射处理：如 Spring 框架的 `@Value`、`@Component` 通过反射处理。

## 交互中延展理解（非参考答案要求）

- `@Retention` 保留策略决定注解存活范围：`SOURCE`（源码期）、`CLASS`（字节码期）、`RUNTIME`（运行期）。Spring 注解为 `RUNTIME`，因此元数据完整保留到 JVM 运行期，编译器虽能读到注解但不实现 Spring 的装配逻辑，真正的功能由框架运行期反射完成。这一条有助于理解"运行期反射处理"，但不属于参考答案必答点。
