## 三、需重点学习

### 1. 构造方法的完整特点（第40题）

四个要点需记牢：①名字与类名相同；②没有返回值且不能用void声明；③生成对象时自动执行无需调用；④不能被重写（override）但可以重载（overload）。

> 易错点：构造方法**不能被重写**，因为重写要求方法名与父类一致，而构造方法名强制等于类名，父子类名不同所以无法重写。

### 2. 接口vs抽象类的成员变量差异（第44题）

- 接口成员变量：只能是 `public static final` 常量，不能修改且必须有初始值
- 抽象类成员变量：默认 default 访问级别，可在子类中重新定义和赋值
- 补充：接口 Java 8 起支持 `default` 默认方法（有方法体）

### 3. 对象相等vs引用相等的实现层面（第37题）

- 对象相等：比较内容，通过 `equals()` 方法实现（默认继承Object的equals仍比较地址，常需重写）
- 引用相等：比较内存地址，通过 `==` 实现

### 4. 向下转型的安全风险和instanceof（第46题）

- 安全情况：父类引用实际指向子类对象，转回原类型安全
- 不安全情况：父类引用指向父类对象，强转子类类型→运行时 ClassCastException
- 避免方法：转型前用 `instanceof` 判断

### 5. Java不支持多继承的原因（第42题）

- 菱形继承问题：多个父类有相同方法/属性时，子类不知道继承哪个
- 弥补手段：接口（可多实现）和内部类

### 6. 面向对象三大特征的深度细节（第41题）

- **封装**：核心是"属性私有化 + 提供公共方法（getter/setter）控制访问"，不是简单"封装在一个类里"
- **继承**：子类拥有父类所有成员（含私有，但私有不可访问只是拥有）；可扩展；可覆盖父类方法
- **多态**：父类引用指向子类实例；运行期决定执行哪个类的方法；不能调用子类独有方法；子类重写则执行子类方法
