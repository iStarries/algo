### 第67题：什么是泛型？有什么作用？

参考答案中有但未提及：

- **泛型最大的好处是提高代码复用性**。以 `List` 为例，可以放 String、Integer 等多种类型；不用泛型的话，存放 String 要写一个 List 接口，存放 Integer 要写另一个 List 接口，泛型用一个接口解决。
- **JDK 5 中引入的新特性**。答背景时提一句更完整。
- （已覆盖）编译器检测、类型安全、可读性、稳定性、免手动类型转换。

### 第69题：项目中哪里用到了泛型？（被跳过）

参考答案中的项目场景：

- 自定义接口通用返回结果 `CommonResult<T>`，通过参数 T 动态指定返回数据类型
- 定义 Excel 处理类 `ExcelUtil<T>`，动态指定 Excel 导出的数据类型
- 构建集合工具类（参考 `Collections` 中的 `sort`、`binarySearch` 方法）

面试中"项目哪里用了泛型"属于实证题，答出具体类名 + 用途比泛泛而谈效果好。

## 面试过程要点记录

- 第67题追问：参考答案"免去手动类型转换"指的是向下转型——原生 List 返回 Object，取用时需 `(Person) list.get(0)` 手动强转（向下转型）；泛型后编译器自动插入转换代码，编译期即拦截类型错误。
- 第68题追问：
  - 泛型方法 `<E>` 的位置固定：修饰符之后、返回类型之前，不能放在方法名后；类/接口的泛型贴名字后，方法声明自己的泛型才放返回类型前。
  - raw type（原始类型）：不填泛型合法（JDK 5 向后兼容），但退化为 Object、无类型检查、取出需手动强转、编译器警告；`new ArrayList<String>()` 与 `new ArrayList()` 是两回事。
  - "实例化必须指定类型"的准确表述：要发挥泛型约束作用就必须指定；raw type 是语法允许但规范不推荐的退化用法。
