## 需重点学习

1. **栈帧四要素**：局部变量表、操作数栈、动态链接、方法出口——第 1、4 题两次遗漏，高频考点，需固化。
2. **程序计数器两个作用**：行号指示器实现流程控制 + 多线程切换后恢复执行位置；"唯一不 OOM"特性。
3. **栈溢出两种异常**（第 7 题）：StackOverflowError（栈深度超限，递归典型）与 OutOfMemoryError（动态扩展申请不到内存，HotSpot 不支持扩展）；`-Xss` 参数。
4. **intern 机制**（第 8 题）：String.intern 的作用、死循环调用导致常量池溢出的复现路径、1.7 前后常量池位置变化。
5. **参数名记忆**：`-XX:PermSize`/`-XX:MaxPermSize`、`-XX:MetaspaceSize`/`-XX:MaxMetaspaceSize`、`-Xss`、`-Xms`/`-Xmx`——多处提到但从未完整说出，面试场景下说不出参数名显得不扎实。
6. **术语精度**：元空间（曾误写"原空间"）、"元空间在本地内存"与"永久代在堆"的标准对比表述。
