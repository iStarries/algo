## 需重点学习

以下为参考答案中未覆盖的要点，按题目顺序列出：

**第11题** — Stack：继承 Vector 的同步容器，方法用 synchronized 修饰，后进先出（LIFO）。另外"ArrayList 扩容增加 50%""ArrayList/LinkedList 均非线程安全"这两个维度也需补入。

**第14题** — "ArrayList 和 LinkedList 都是不同步的，即都不保证线程安全"是本题第一个对比维度，答题时容易只顾结构差异而漏掉。内存空间占用：ArrayList 的浪费在结尾预留容量空间，LinkedList 的浪费在每个元素要存放直接前驱和直接后继。

**第16题** — 扩容方法调用链：add() → ensureCapacityInternal() → calculateCapacity() → ensureExplicitCapacity() → grow()（扩容至 1.5 倍）→ Arrays.copyOf()（复制到新数组）。面试官追问源码实现时需要。

**第18题** — CopyOnWriteArrayList：java.util.concurrent 包下的线程安全 List，与 Vector、synchronizedList 并列的第三个方案，读多写少场景首选。

**第19题** — 方法名：重写 writeObject()，内部先调用 defaultWriteObject() 序列化非 transient 元素，再遍历 elementData 只序列化已存入的元素，从而加快序列化速度、减小文件大小。
