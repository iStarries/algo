## 需重点学习

以下为参考答案中未覆盖的要点，按题目顺序列出：

**第2题** — PriorityQueue：优先队列，可按比较器或元素自然顺序排序。7 个常用实现类中唯一遗漏的一个。

**第3题** — Hashtable 和 Stack 作为线程安全集合的典型代表，面试常与 HashMap/ConcurrentHashMap 放在一起考察，需要记住。另外"JDK 1.5 后 java.util.concurrent 并发包"这个背景也值得提及。

**第4题** — ConcurrentModificationException 这个异常名需要记住，fail-fast 的核心就是抛这个异常。

**第5题** — 两个关键变量名：`modCount`（集合级别的修改计数器）和 `expectedModCount`（迭代器创建时复制的副本），遍历前比对两者，不一致则抛 ConcurrentModificationException。这是底层实现的核心，名字要准确。

**第6题** — Collections "不能被实例化"这一特征，区别于 Collection 作为接口的定义。

**第7题** — List/Set/Map 三者区别建议按多维度记忆：继承接口（List/Set 继承 Collection，Map 不继承）、常见实现类、常见方法（List 用 add/get，Map 用 put/get）、线程安全（Vector/Hashtable）。单维度回答容易被面试官追问。

**第8题** — 补充三种遍历方式：ListIterator（双向遍历+迭代中修改）、forEach（Java 8）、Stream API（Java 8，支持过滤/映射等函数式操作）。Java 8 后两种是面试高频考点。

**第9题** — Iterator 取代了 Java 集合框架中的 Enumeration，这是历史背景知识点。

**第10题** — 精确记住完整方法名 `Collections.unmodifiableCollection(Collection c)` 和异常名 `UnsupportedOperationException`。类名是 Collections（带 s 的工具类），不是 Collection。
