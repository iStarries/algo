## 需重点学习

- **第21题**：Comparable 出自 java.lang 包、Comparator 出自 java.util 包；同一对象支持多种排序规则的方式——类内重写 compareTo 定一种，类外多个 Comparator 补其余规则。
- **第23题**：HashSet.add() 底层调用 HashMap.put()；key 重复时新 value 覆盖旧 value 并返回旧 value，这是"不重复"的机制保证。
- **第24题**：三者均非线程安全；LinkedHashSet 底层是链表+哈希表、TreeSet 底层是红黑树；应用场景一一对应——无顺序要求用 HashSet、插入取出顺序保证 FIFO 用 LinkedHashSet、自定义排序用 TreeSet。
- **第20题**：判重完整链路 = hashCode 确定存储位置 → equals 判断是否已存在 → 已存在则不插入。
